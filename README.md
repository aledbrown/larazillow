### Master Laravel, Vue 3, Inertia (VILT Stack)
> https://www.udemy.com/course/master-laravel-6-with-vuejs-fullstack-development/

### General
> php artisan migrate:rollback --step=1
> composer dump-autoload

### Info
# Install Vue
> npm install --save-dev @vitejs/plugin-vue

# Install Inertia - https://inertiajs.com/client-side-setup
> npm install @inertiajs/vue3

# Install ESLint
> npm install --save-dev eslint eslint-plugin-vue

# Install Prettier (didn't use this)
> npm install --save-dev prettier eslint-plugin-prettier

# Install Ziggy
> composer require tightenco/ziggy
> https://github.com/tighten/ziggy

# Install Tailwind CSS
> https://tailwindcss.com/docs/guides/vite#vue
> npm install -D tailwindcss postcss autoprefixer 
> npx tailwindcss init -p
> npm install -D @tailwindcss/forms
